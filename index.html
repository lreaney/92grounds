How to play

Type and press Enter

Type a ground and it drops onto the map in its league colour. If nothing else could match what you've typed, it's accepted before you press Enter. Small typos are forgiven when you press Enter.

Old names count

Former names and sponsor names count as well as the current one. In Clubs mode, common nicknames and short forms count too.

Beat the clock

The timer starts with your first keystroke and stops when you reach 92 or give up. Pause hides the map so nobody can peek. Your best time is saved for each mode.

Shared names

A few names belong to more than one ground. Each entry places only one of them, so type the name again for each ground that shares it.
